asset-kit.js、asset-kit-parts.js、asset-kit-assets.js を個別に説明します。共通APIの役割、部品カタログの各登録項目、キット製アセット全件の一覧も載せています。

最初に結論：asset-kit.jsは「形を作る道具」、asset-kit-parts.jsは「使い回す部品」、asset-kit-assets.jsは「部品を組み立てた完成アセット」です。

1. 3ファイルの関係

asset-kit.js
  └─ ASSET_KIT APIを作成：輪郭、押し出し、部品、線・面への変換
       ├─ asset-kit-parts.js：window / door / bench など共通部品を登録
       └─ asset-kit-assets.js：ASSET_KIT.define(kind, meta, builder)で完成形を登録

builderが返すparts → partEdges()で線、partTris()で面 → L2W()でワールド座標
              → engine-render.jsの深度・隠線処理、選択範囲計算へ

座標はローカル座標で、Xは左右、Yは前後、Zは高さ（上がプラス）。正面は多くの部品で-Y側です。配置・回転・接着の変換はエンジンのL2W()に任せます。

2. asset-kit.js — API本体を機能ごとに

ファイル冒頭では「同じ形の記述から線と面を作る」という目的、ローカル座標、partのフィールドを説明しています。続く本体は小さな機能群に分かれています。

2-A. 寸法値と座標変換

num / param

数値の安全な読み取り。paramは編集中のo[key]を優先し、次にASSETSの初期値、controlsのdefault、最後にfallbackを参照。

toP3(axis,u,v,w)

2D輪郭座標と押し出し位置を3Dローカル点へ変換。axisごとの座標面を統一する。

keepAnchorPatch

形の寸法を変えた時、ワールド上の基準位置が動かないようoffを補正する。

2-B. 輪郭を作る・変形する

rectPath

中心・幅・奥行きを指定する四角形輪郭。

circlePath

円を多角形として近似した輪郭。分割数が滑らかさと線分数を左右する。

ringPath / roundRectPath

角丸矩形の断面を作る。ringPathは固定数の点を揃える必要がある断面積層にも使う。

offsetPath / scalePath / rotatePath

輪郭の平行移動、拡大縮小、回転。

insetPath

輪郭を内側へ縮める。枠・ベベルなどの内周作りに用いる。

count / repeat / grid

個数を範囲内へ整え、部品を繰り返し・格子配置する。

2-C. 立体部品を作る

extrude / prism / box

2D輪郭を押し出す汎用プリミティブ。boxとprismは読みやすさ・互換性の別名として使われる。

sheet

板・シート用。用途に応じて側面線の表現を抑える。

cylinder

軸と分割数を指定する円柱。

depthBeveledBox

奥行き方向の辺だけ角丸にした箱。seam候補をつける設定も可能。

loft / revolution

複数断面をつなぐ立体、または断面を回転させる回転体。

roundedBox

丸みを持たせた箱の形状生成。

face3 / wire

任意の3D面や輪郭線を表現する。

recessedWall

凹みを持つ壁など、開口・後退を含む形状を組み立てる補助。

2-D. 部品カタログと移動

registerPart(name,builder)で部品を登録、partNames()で登録名を得ます。part(name,opts)で生成し、opts.at=[x,y,z]があれば部品群をその位置へ動かします。moveParts(parts,dx,dy,dz)は押し出し、rings、自由メッシュなど形状形式ごとの正しい軸で移動します。

repeatParts(parts,{axis,spacing,count,group})は部品一式を複製配置します。seamMarksのkeyもコピーごとに分け、輪郭判定が別部品の同名箇所と混ざらないようにします。

2-E. 部品から線と面へ

partEdges(part)

押し出し輪郭・rings・meshEdges・自由polyを線分列に変える。円筒の輪郭候補は視点に合わせて選べる。

partTris(part)

部品を三角形面へ変換。穴のある多角形はbridgeHoles等を使い、面を分割する。

triangulate / bridgeHoles

多角形を三角形に分け、穴を含む形の面を扱う補助処理。

isConvex / area2

多角形の凸性・符号付き面積の判定に使う。

bevelMarks

ベベル角の輪郭候補に識別マークを付け、重複・不要線の制御を助ける。

2-F. 編集ハンドル・曲線支援

axisHandle

軸方向に伸びる寸法編集ハンドルの基準点を作る。

hoodControls

ひさしの傾き、枠長さ、つば、厚さなど定型コントロールを作る。

quadraticPoint / quadraticEditor / quadraticTube

二次ベジェ曲線上の点、編集項目、曲線に沿う管形状を支援する。

textStrokes / textPart / glyphs

文字やグリフを線・部品として扱うための関数群。

2-G. アプリ本体へ公開する出口

define()はmetaをASSETSへ登録し、線画builderをASSET_LINE_BUILDERSへ接続します。同時にKIT_POINTSとKIT_TRISを登録。window.assetKitBoundsPoints(o)とwindow.assetKitTriangles(o)はエンジンが選択範囲や三角形を受け取る窓口です。

このキットは形状の共通化・線と面の整合を助けるものです。関数再利用だけでGPUインスタンシングや速度向上が保証されるわけではありません。

API一覧

define

アセット登録。kind・meta・builderを受け取り、線生成と面生成の関数を登録する。

param

ユーザー編集値・初期値・コントロール既定値を順に参照する。

rectPath / circlePath / roundRectPath

2D輪郭を作る。押し出しや穴の境界の入力に使う。

box / extrude / prism

2D輪郭を軸方向へ押し出して立体部品にする。

sheet

板・シート状の部品を表す。

cylinder / depthBeveledBox

円柱や奥行き方向の角を丸めた箱を作る。

loft / revolution / roundedBox

断面をつないだ立体、回転体、丸みのある箱を作る。

face3 / wire

自由な3D面や線形状を表す。

moveParts

部品群をローカル座標で移動する。

registerPart / part / partNames

再利用部品の登録、生成、登録名確認。partはatで配置位置を指定できる。

repeat / repeatParts / grid / count

個数を制限しながら規則配列・格子配列を作る。

offsetPath / scalePath / rotatePath / insetPath

輪郭の移動、拡大縮小、回転、内側オフセット。

bevelMarks

ベベル輪郭候補を識別し、稜線の選別に使う印を作る。

partEdges / partTris

部品データを線分と三角形面へ展開する。

axisHandle / hoodControls / quadraticEditor

編集ハンドルや曲線編集コントロールを構成する補助API。

keepAnchorPatch

寸法変更後も基準位置を保つための補正値を計算する。

triangulate / bridgeHoles / isConvex / area2

多角形の三角形分割、穴の処理、凸性・面積など形状処理の補助。

assetKitBoundsPoints / assetKitTriangles

キット形状の選択範囲点とワールド座標三角形をエンジン側へ渡す窓口。

3. asset-kit-parts.js — 登録部品を一つずつ

このファイルは即時関数の中でASSET_KITを確認し、利用可能なら各部品名をregisterPartで登録します。ここにある部品は完成品ではなく、別のアセットのbuilderから再利用する形状です。

windowwindow

穴あき枠にガラスや縦桟を加える窓。

doordoor

枠・扉板・任意の取っ手をまとめる。

acUnitacUnit

室外機の箱、ファン、ガラリ、脚を組み立てる。

benchbench

座面・脚・任意の背もたれを構成する。

screenHoodscreenHood

画面用ひさしの輪郭・枠・面を作る。

awningawning

斜めの幕、垂れ、支え腕をまとめる。

wheelwheel

タイヤ、ハブ、スポークを作る。

pipeRunpipeRun

経路に沿う配管形状を作る。

pentaPrismpentaPrism

五角形断面を押し出す立体。

tiretire

車輪用タイヤ形状を作る。

signBoardsignBoard

標識・看板の板状部品。

部品呼び出しの読み方

K.registerPart("window", (o) => {
  // oから幅・高さ・枠厚などを読む
  // K.rectPathで外枠・開口の輪郭を作る
  // K.box(..., {axis:"y", holes:[opening], holeSides:true})で枠を立体化
  // 必要に応じてK.sheetでガラスを足す
  return parts;
});

// 利用側：部品名とパラメータを渡す
const windowParts = K.part("window", {
  w: 0.9, h: 0.7, frame: 0.06, at: [0, 0, 1.2]
});

部品ごとに「原点がどこか」「前面がどちらか」「寸法の意味」を揃えると組み合わせやすくなります。実際の個別設定は該当registerPartの関数を確認してください。

一件の定義を読む順序

  1. ASSET_KIT.define("kind", meta, builder)でkindを見つける。
  2. metaのlabel・glyph・groupを見て棚での表示を確認。
  3. w・d・h・accent、固有値、controlsを読む。
  4. builder内でoから寸法を読み、KのAPI・共通部品を呼び、partsを返している順に追う。
  5. 線画と面、ハンドル、範囲点、保存値が同じパラメータに結びついているか確認。
asset-kit-assets.jsには一部、既存アセットの移行定義や他ファイルの幾何関数との連携もあります。すべてが単純なboxの配列だけでできているわけではありません。

5. 変更の手順とテスト

  1. 編集するkindまたは部品名を検索。
  2. 入力値の範囲、ローカル座標、前面・押し出し軸を確認。
  3. 線と面の一致、隠線、複数視点を確認。
  4. コントロールの値、保存・読込・複製を検査。
  5. 関連するtestsを実行し、必要なら回帰テストを追加。

最終的な正本は実ソースです。本ガイドの説明や一覧と食い違う時は、該当のJS実装と呼び出し元を確認してください。
